# Footbal Predictor

A standalone football odds predictor built from clean historical game rows.

## Use Online Or Locally

Open `index.html` in any browser.

The app works offline after downloading because all prediction logic and data are embedded in the HTML file.

## Data Rule

The predictor uses only:

- Home odds
- Draw odds
- Away odds
- Final score

It ignores Under/Over columns, percentage columns, and duplicate rows.

## Features

- 482 unique clean game rows
- Imported `betss.docx` archive notes for easier row auditing
- 1X2 probability blend
- Poisson likely scorelines
- KNN archive matching
- Kelly edge/stake guidance
- Upset-risk signal
- KSh betting spot capped between 1 and 50 shillings
- Copyable prompt for Claude, Grok, Kimi, or ChatGPT second opinion
